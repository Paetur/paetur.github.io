# Pætur & Maria Hentze — Wedding website

Mobile-first wedding invitation with Faroese, English and German language support.

## Structure

- `index.html` — public invitation
- `css/style.css` — shared visual styles
- `js/config.js` — public Supabase URL + anon frontend key
- `js/supabase.js` — Supabase client
- `js/languages.js` — FO/EN/DE copy
- `js/invitation.js` — invitation loading/rendering
- `admin/index.html` — separate admin entry point (Auth/dashboard comes later)
