Put your configuration online

Administrator verified. Your website configuration is ready.

Download config.js, and add it to js/config.js in your NEW GitHub repository. This step is essential: browser-only setup does not configure the public website for other visitors.

The file contains only your Supabase URL and publishable / anon key. It must not contain a secret or service_role key.

After committing config.js, enable GitHub Pages for the new repository. Then open the website, verify admin sign-in and invitation behavior. Keep the event unpublished until final security checks pass.
